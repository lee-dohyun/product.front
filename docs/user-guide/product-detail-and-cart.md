## 1. 이 기능으로 할 수 있는 일

상품 상세 화면에서 가격·옵션·재고와 함께, 구매 전에 알아야 할 상품 정보(원산지·제조사 등)와
배송비·반품 조건을 확인하고 장바구니에 담습니다.

## 2. 시작하기 전에

- 로그인하지 않아도 장바구니에 담을 수 있습니다. 찜하기는 로그인해야 합니다.

## 3. 따라 하기

### 3-1. 상품 정보 확인하기
1. 상품을 누르면 상세 화면이 열립니다 → 이름, 사진, 가격이 보입니다.
2. 색상·사이즈 같은 옵션이 있으면 고릅니다 → 고른 조합의 가격과 재고가 보입니다.
   고른 조합을 팔지 않으면 「이 옵션 조합은 판매하지 않습니다」, 재고가 없으면 「품절」이 보입니다.
3. 화면 아래쪽에서 다음을 확인합니다(판매자가 입력한 상품만 보입니다).
   - **「상품정보제공고시」**: 법으로 정한 상품 정보(예: 화장품이면 용량·제조업자·사용기한·전성분). 입력되지 않은 항목은 「-」로 보입니다.
   - **「배송·교환·반품 안내」**: 배송비(예: 「무료배송」, 「3,000원 (50,000원 이상 구매 시 무료)」), 출고 소요일(「결제 후 N영업일 이내 출고」), 제주·도서산간 추가 배송비, 반품 배송비(편도), 교환 배송비(왕복), 반품·교환 주소.
     판매 기간·1회 최대 구매 수량·KC 인증이 있는 상품은 그 줄도 함께 보입니다.

### 3-2. 장바구니에 담기
1. 「장바구니 담기」를 누릅니다 → 버튼이 「담는 중...」에서 「담았습니다」로 바뀌면 담긴 것입니다.
2. 담기지 않으면 버튼 위에 이유가 빨간 글씨로 보입니다(6번 표 참고).

### 3-3. 장바구니에서 수량 바꾸기
1. 장바구니 화면에서 수량을 바꿉니다.
2. 바꿀 수 없으면 이유가 보이고 수량은 그대로입니다(예: 1회 최대 구매 수량 초과).

### 3-4. 찜하기 / 찜 취소 (로그인 필요)
1. 「♡ 찜하기」를 누릅니다 → 버튼이 「♥ 찜 취소」로 바뀌면 찜 된 것입니다.
2. 이미 찜한 상품의 상세 화면을 다시 열면 처음부터 「♥ 찜 취소」로 보입니다. 누르면 찜이 풀리고 「♡ 찜하기」로 돌아갑니다.
3. 찜한 상품 목록은 화면 위 「찜」 아이콘 → 마이페이지 「내 찜 목록」에서 봅니다.

### 3-5. 회원 등급 할인 확인하기
1. 로그인한 상태로 장바구니를 엽니다 → 할인이 있는 등급(실버·골드·VIP)이면 합계 자리에 세 줄이 보입니다.
   - 「상품 합계: N원」
   - 「(등급 이름) 등급 할인 (N%): -N원」
   - 「결제 예정 금액: N원」
2. 주문·결제를 마치면 완료 화면의 결제 금액 옆에 「(회원 등급 할인 N원 적용)」이 보입니다.
3. 할인이 없는 등급(일반)이거나 로그인하지 않았으면 예전처럼 「합계: N원」 한 줄만 보입니다.

## 4. 입력 항목 설명

해당 없음(이 화면에서 입력하는 것은 옵션 선택과 수량뿐입니다).

## 5. 상태와 진행 흐름

| 화면 표시 | 뜻 | 할 일 |
|---|---|---|
| 재고 N개 | 살 수 있음 | 「장바구니 담기」 |
| 품절 | 재고 없음 | 다른 옵션 선택 또는 나중에 |
| 이 옵션 조합은 판매하지 않습니다 | 그 조합은 팔지 않음 | 다른 옵션 선택 |
| 판매 중단 | 판매자 사정으로 지금은 팔지 않음. 상품 정보는 그대로 볼 수 있고 「장바구니 담기」 버튼이 눌리지 않음 | 나중에 다시 확인 |

## 6. 자주 보는 메시지와 해결 방법

| 화면 메시지(원문) | 원인 | 해결 |
|---|---|---|
| 이 상품은 1회 최대 N개까지 구매할 수 있습니다. | 판매자가 정한 한 번에 살 수 있는 수량을 넘음(같은 상품의 다른 옵션도 합쳐서 계산) | 수량을 줄이기 |
| 판매자 사정으로 판매가 중단된 상품입니다. | 판매자가 판매 중단 상태(상세 화면을 열어 둔 사이에 바뀐 경우 등) | 나중에 다시 시도 |
| 지금은 판매 기간이 아닙니다. | 판매 시작 전이거나 판매가 끝남 | 판매 기간에 다시 시도 |
| 판매하지 않는 상품이 포함되어 있습니다. | 주문하려는 상품 중 판매가 끝났거나 중지된 것이 있음 | 장바구니에서 그 상품을 빼고 주문 |
| 「(상품 이름)」 상품의 재고가 부족합니다. 지금 주문할 수 있는 수량은 N개입니다. | 「주문하기」를 누른 순간 남은 수량보다 많이 담겨 있음(같은 옵션을 여러 줄로 담았으면 합쳐서 계산) | 그 상품의 수량을 N개 이하로 줄이고 다시 「주문하기」 |
| 「(상품 이름)」 상품이 품절되었습니다. | 그 상품(옵션)이 다 팔림 | 장바구니에서 그 상품을 빼고 주문 |
| 재고가 부족해 결제를 완료할 수 없습니다. | 「주문하기」를 누른 뒤 결제가 끝나기 전에 다른 주문이 먼저 남은 수량을 가져감(드묾) | 장바구니에서 수량을 줄이거나 그 상품을 빼고 다시 주문 |
| 장바구니에 담지 못했습니다. 잠시 후 다시 시도해 주세요. | 일시적인 오류 | 잠시 후 다시 시도 |
| 수량을 바꾸지 못했습니다. | 일시적인 오류 | 잠시 후 다시 시도 |
| 주문에 실패했습니다. 입력값을 확인해주세요. | 주문 정보 누락 또는 일시적인 오류 | 받는 분·연락처·주소 확인 후 다시 시도 |
| 이미 다른 주문에 쓰인 요청입니다. 장바구니를 새로 고친 뒤 다시 주문해주세요. | 같은 주문 요청을 다른 내용으로 다시 보냄(드묾) | 화면을 새로 고친 뒤 다시 주문 |
| 주문 요청을 보내지 못했습니다. 잠시 후 다시 시도해주세요. | 인터넷 연결이 끊겨 요청이 서버에 닿지 못함 | 연결 확인 후 다시 「주문하기」 |
| 찜하기 처리에 실패했습니다. 로그인 상태를 확인해주세요. | 로그인하지 않았거나 로그인이 만료됨 | 로그인 후 다시 시도 |

## 7. 알아 둘 제한 사항

- 판매 기간이 아닌 상품도 상세 화면에는 보입니다. 담기·주문만 막힙니다.
- 「판매 중단」 상품도 목록·상세에는 보입니다. 이미 장바구니에 있던 것은 목록에 남지만 주문 단계에서 「판매하지 않는 상품이 포함되어 있습니다.」로 막힙니다.
- 「상품정보제공고시」·「배송·교환·반품 안내」는 판매자가 입력한 상품에만 보입니다.
- 등급 할인액은 원 미만을 버립니다(예: 990원의 2%는 19원). 실제 결제 금액은 주문하는 순간의 등급으로 정해지며, 등급은 매월 1일에 다시 산정됩니다.
- 등급 정보를 불러오지 못하면 장바구니에는 「합계」만 보입니다. 이때도 주문에는 등급 할인이 적용될 수 있으니 완료 화면의 결제 금액을 확인하세요.
- 장바구니에는 남은 수량보다 많이 담을 수 있습니다. 남은 수량은 「주문하기」를 누를 때 확인합니다 — 담아 둔 사이에 다른 고객이 먼저 살 수 있어, 담는 시점의 수량으로는 보장할 수 없기 때문입니다.
- 로그인하지 않은(비회원) 주문에는 등급 할인이 없습니다.
- 「주문하기」 뒤 서버 응답이 늦으면(서비스 업데이트 직후 등) 화면이 자동으로 한 번 더 요청합니다. 같은 내용의 재요청은 **새 주문을 만들지 않고 처음 주문을 이어서 처리**하므로, 실패 메시지를 보고 같은 장바구니로 다시 「주문하기」를 눌러도 주문이 두 개 생기지 않습니다. 화면을 새로 고친 뒤 다시 누르면 새 주문으로 봅니다.

## 8. 문의

주문·배송 문의는 쇼핑몰 고객센터로 연락해 주세요.
