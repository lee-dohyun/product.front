# 비회원 주문 조회·취소하기 사용 설명서

| 항목 | 내용 |
|---|---|
| 대상 | 로그인하지 않고 주문한 고객(비회원) |
| 화면 주소 | <https://product.posselect.com/guest-order> |
| 필요한 권한 | 없음(주문번호 + 주문할 때 적은 연락처, 또는 주문 확인 메일의 링크) |
| 최종 확인 | (미확인) — 2026-10-14 자동 테스트(조회·링크 열기·불일치 안내)만 통과. 배포 전이라 실제 화면으로는 아직 확인하지 못했다 |
| 관련 이슈 | lee-dohyun/gateway#323 |

## 1. 이 기능으로 할 수 있는 일
로그인하지 않고 주문한 주문을 다시 열어 상품·결제 금액·배송 상태·운송장을 확인하고, 출고 전 취소·배송 완료 후 반품·교환을 신청한다.

## 2. 시작하기 전에
- 비회원으로 주문할 때 「주문 확인 이메일」을 꼭 적어야 한다. 결제가 끝나면 그 주소로 주문번호와 조회 링크가 간다.
- 주문 완료 화면의 「주문 조회하기」 링크도 같은 화면을 연다.

## 3. 따라 하기
### 3-1. 메일 링크로 열기
1. 주문 확인 메일의 「주문 조회:」 다음 링크를 누른다 → 주문 상세가 바로 열린다.

### 3-2. 주문번호와 연락처로 찾기
1. <https://product.posselect.com/guest-order> 를 연다.
2. 「주문번호」(숫자)와 주문할 때 적은 「연락처」를 입력하고 「주문 조회」를 누른다.
3. 주문 상세가 열린다. 주소가 링크 모양(`?id=…&token=…`)으로 바뀌어 새로 고쳐도 다시 묻지 않는다.

### 3-3. 취소·반품·교환
마이페이지의 주문 상세와 같다 — 「취소·반품·교환」에서 신청한다(출고 전 취소, 배송 완료 7일 안 반품·교환).

## 4. 입력 항목 설명
| 항목 | 필수 | 형식·제한 | 예 |
|---|---|---|---|
| 주문 확인 이메일(장바구니) | 비회원 주문은 필수 | 이메일 형식, 200자 이내 | me@example.com |
| 주문번호 | 조회할 때 필수 | 숫자 | 42 |
| 연락처 | 조회할 때 필수 | 주문할 때 적은 번호(하이픈 있어도 됨) | 010-1234-5678 |

## 5. 상태와 진행 흐름
마이페이지 주문 상세와 같다.

## 6. 자주 보는 메시지와 해결 방법
| 화면 메시지(원문) | 원인 | 해결 |
|---|---|---|
| 「주문을 찾을 수 없습니다. 주문번호와 연락처를 확인해주세요.」 | 주문번호나 연락처가 맞지 않거나, 회원으로 한 주문이다 | 메일의 주문번호와 주문할 때 적은 연락처를 다시 확인한다. 회원 주문은 마이페이지에서 본다 |
| 「비회원 주문은 주문 확인을 받을 이메일을 입력해야 합니다.」(장바구니) | 이메일을 비워 두고 주문했다 | 이메일을 적는다 |

## 7. 알아 둘 제한 사항
- 조회 링크(메일·완료 화면)를 가진 사람은 누구나 그 주문을 볼 수 있다. 다른 사람과 공유하지 않는다.
- 주문 확인 메일이 오지 않으면(스팸함 확인 후) 주문번호와 연락처로 찾는다.
- 회원으로 로그인해 한 주문은 이 화면에서 찾을 수 없다.

## 8. 문의
주문·배송 문의는 쇼핑몰 고객센터로 연락한다.
